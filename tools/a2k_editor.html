Apple II — Joy-Map .a2k Editor

Assign Apple II keys to gamepad buttons for the MiSTer core. Pick a button (or its small +Shift box), then click a key. Save a 16-byte .a2k and load it on the core via OSD → System & BIOS → "Load Joy Map".

Click a button to select it (highlighted ■), then click a key on the right to assign. The small box in the bottom-right of each key button is its +Shift mapping (hold Select to use it); if a +Shift mapping is blank the core falls back to the unshifted key. Start shows/hides the virtual keyboard and Select is the shift — neither is mapped here.
